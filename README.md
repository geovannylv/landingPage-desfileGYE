# Desfile de Carros Alegóricos de Guayaquil

Landing page informativa sobre el desfile de carros alegóricos de las fiestas de independencia de Guayaquil. El proyecto busca presentar los principales atractivos del evento, mostrar imágenes relacionadas con la celebración y reunir opiniones de asistentes para ofrecer una experiencia de consulta clara y organizada.

## Objetivo del proyecto

Desarrollar una página web adaptable a diferentes dispositivos que permita a los visitantes conocer el desfile, explorar sus elementos culturales y visuales, consultar información de interés y acceder a fuentes institucionales.

## Contenido de la página

La landing page se organiza en las siguientes secciones:

- **Inicio:** presentación del evento y navegación principal.
- **Sobre el desfile:** contexto de la celebración y sus elementos culturales.
- **Carros alegóricos:** presentación visual de las carrozas y sus características.
- **Experiencias de los asistentes:** síntesis de las opiniones recopiladas mediante entrevistas.
- **Información para visitantes:** orientación para consultar información oficial sobre el evento.
- **Fuentes y contacto:** referencias utilizadas y créditos del proyecto.

La información sobre fechas, horarios, recorridos y recomendaciones debe verificarse mediante fuentes oficiales antes de su publicación definitiva.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** presentación visual y adaptación a diferentes tamaños de pantalla.
- **JavaScript:** funcionalidades incluidas en los archivos originales de la plantilla, cuando corresponda.
- **Git y GitHub:** control de versiones y almacenamiento del código fuente.

## Plantilla utilizada

El desarrollo parte de **Halcyonic**, una plantilla gratuita de [HTML5 UP](https://html5up.net/halcyonic).

Se seleccionó por su estructura organizada en secciones y columnas, la combinación de texto e imágenes y su diseño adaptable. La plantilla se personalizó para reemplazar el contenido de demostración por información relacionada con el desfile de carros alegóricos de Guayaquil.

Durante la planificación también se compararon las plantillas [Dimension](https://html5up.net/dimension) y [Forty](https://html5up.net/forty).

## Instalación y ejecución local

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/geovannylv/landingPage-desfileGYE.git
   ```

2. Entrar en la carpeta del proyecto:

   ```bash
   cd landingPage-desfileGYE
   ```

3. Abrir el archivo `index.html` en un navegador web.

No se requiere un proceso de compilación para visualizar la página estática. Para comprobar su funcionamiento, se recomienda verificar que las imágenes y los archivos CSS y JavaScript se carguen correctamente.

## Estructura del proyecto

La estructura se basa en los archivos de la plantilla Halcyonic y sus recursos:

- `index.html`: estructura y contenido principal de la landing page.
- `assets/css/`: hojas de estilo.
- `assets/js/`: scripts incluidos en la plantilla.
- `images/`: imágenes utilizadas en las secciones de la página.
